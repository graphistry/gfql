# gfql Documentation

## Overview

gfql (Graph dataFrame Query Language) is an open source embeddable graph wrangling library with native in-memory large-scale columnar computing.

## Installation

```bash
pip install gfql
```

## Quick Start

```python
import gfql

# Your graph query code here
```

## Features

- Embeddable graph wrangling
- Native in-memory columnar computing
- Large-scale data processing
